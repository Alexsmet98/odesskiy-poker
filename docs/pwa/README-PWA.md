# Одесский покер — веб-приложение 0.2.0

Разработчик приложения — **imerkoev**.

Одна версия для iPhone, iPad, Android, складных телефонов и компьютеров. Интерфейс рассчитан начиная с iPhone 7: 375 × 667 CSS-пикселей, iOS 15. На телефоне карты переносятся на следующую строку, на широком экране журнал расположен рядом со столом. Размер окна и поворот не создают новую партию. У полей ввода шрифт 16 px, у кнопок высота от 44 px; учитываются вырезы экрана и экранная клавиатура.

## Размещение на действующем сайте

Приложение должно находиться **на том же HTTPS-домене, что и сервер игры**. Оно использует существующие `/api/...`, общие столы и голосовой сервер. Доступа к аккаунту Apple, Mac или подписки разработчика не требуется.

### Готовая сборка из комплекта

1. Скопировать папку `public/app` из комплекта в `public/app` действующего проекта игры, сохранив все вложенные файлы.
2. Если сайт работает в контейнере, включить папку в образ и выполнить обычное обновление контейнера. Не копировать файлы только во временную файловую систему контейнера.
3. При обычном запуске Next.js перезапустить процесс, чтобы он обнаружил новые файлы в `public`.
4. Открыть `https://odesskiypoker.com/app/index.html`.

Игровые столы сервер хранит в памяти, поэтому перезапуск планировать между партиями. Настройки TURN, хранилище журнала и переменные окружения оставить существующими.

### Сборка из исходников

В полном исходном проекте из `source/`:

```sh
npm ci
npm run build
npm start
```

`npm run build` автоматически создаёт `public/app`, затем собирает основной Next.js-сайт. Его Dockerfile использует ту же команду. Для отдельной сборки приложения: `npm run pwa:build`. После установки обновлённых исходников также работает короткий адрес `/app`.

Не переносить только клиентские файлы на отдельный домен: запросы игры адресуются серверу того же домена. Не кэшировать `/api/` в прокси/CDN. Для `/app/sw.js` и `/app/index.html` использовать проверку актуальности (`Cache-Control: no-cache`); исходный Next.js-конфиг задаёт отдельные заголовки для service worker.

## Как установить

- **iPhone / iPad:** открыть адрес в Safari → «Поделиться» → «На экран Домой» → «Добавить». На новых версиях iOS, если есть переключатель «Открывать как веб-приложение», включить его.
- **Android:** открыть адрес в Chrome → «Установить приложение» в игре или соответствующий пункт меню браузера.
- **ПК:** играть в браузере либо установить через Chrome/Edge, если браузер предлагает установку.

Для первого запуска нужен интернет. После надписи «Игра с ботами доступна без интернета» оболочка, карты и шрифты сохранены. Сетевые партии и журнал требуют интернета. Браузер может очистить локальное хранилище при нехватке места или ручной очистке данных.

## Голос и возвращение в игру

Разрешение на микрофон запрашивается после нажатия кнопки за столом. При сворачивании микрофон выключается; после возвращения включить его снова. Если Safari заблокировал воспроизведение, нажать «Включить звук». Фоновый разговор и работа при заблокированном экране не обещаются.

Место в сетевом лобби запоминается на устройстве. После перезапуска есть кнопка «Вернуться за стол», пока стол ещё существует на сервере. Партия с ботами при полном закрытии начинается заново.

## Отправка логов

«Настройки» → «Отправить логи разработчику». На совместимом телефоне откроется меню отправки: выбрать чат или почту imerkoev. Если отправка файлов браузером не поддерживается, скачается `odesskiy-poker-logs.txt`, который можно приложить к сообщению вручную.

Отчёт содержит ошибки JavaScript, сведения о браузере, версию приложения, размер окна, переходы между экранами и сбои запросов. Журнал ограничен по размеру; последний критический сбой хранится отдельно и сохраняется после перезапуска. Токены, параметры URL, коды столов и известные поля с секретами маскируются. Голос не записывается, отчёты автоматически никуда не отправляются.

После длительной паузы интерфейса или обнаруженного незавершённого сеанса появляется предложение отправить отчёт. Веб-приложение не имеет доступа к системному crash dump iOS/Android и не может гарантировать запись причины полного завершения браузера системой. Уже записанные события остаются доступны, если браузер сохранил свои данные.

## Обновления

Новая версия полностью скачивается перед активацией. Предложение обновиться появляется в меню/настройках; приложение не перезагружает активную партию. Голосовые запросы, игровые действия и ответы API не попадают в офлайн-кэш.

`diagnostics-symbols/0.2.0/` в комплекте — файлы для расшифровки ошибок минифицированной сборки. Хранить у разработчика, на публичный сайт не выкладывать. Для каждой новой сборки сохранять соответствующие `.js` и `.map` из `mobile/dist-pwa/assets`.

## Контроль перед распространением

На настоящем iPhone 7 с актуальной iOS 15 проверить установку, ввод имени с клавиатурой, девять карт на руках, окно джокера, микрофон между двумя устройствами, возврат после сворачивания и отправку отчёта. На Android/Fold проверить оба экрана и поворот; на ПК — узкое/широкое окно. Эти проверки дополняют автоматические проверки сборки и логики кэширования.
